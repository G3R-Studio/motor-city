# Runtime text layout cleanup — 2026-10-04

All three runtime Text creation paths (front end, HUD/modals, garage) now use the same bounds policy. Text uses a fixed font in canvas units, wraps inside its own cell, and has line-height headroom. Best Fit no longer changes typography with the current value or resolution. The HUD factory no longer enlarges text rectangles into neighbouring cells. Visual polish reapplies the policy after responsive composition rather than enabling Best Fit again.

Targeted layout changes:

- About: centred headings/paragraphs, separated introduction, wider/taller cards for the full Russian and English explanations.
- Settings: centred labels/values in their own cells, leaving separate areas for controls.
- Control choice: hint separated from the heading.
- Garage: taller vehicle-name area, separate next-vehicle area, larger character description, wider stat-value cells, centred upgrade titles/levels and navigation labels, right-aligned stat values.
- Results/club: modal sizes preserve space for all rows; reward, mastery, progress, next goal and club rows no longer overlap.
- HUD, navigator, shop: removed value-dependent Best Fit overrides. Existing alignment of numeric columns and prose is preserved where appropriate.

Validation: C# syntax checks, shared text-policy stub checks, existing regression checks, and serialized asset GUID audit passed. No Unity executable is available in this workspace. Unity compilation, actual glyph layout and Play Mode screenshots remain unverified. In Play Mode, check Russian/English, all vehicle names/stat values, long mission/shop text and switching between small/large Game views. Text is generated with vertical Overflow to avoid Legacy Text discarding whole lines at fractional canvas scales. MotorCityTextClip clips the generated triangles to the label rectangle and interpolates glyph UVs. Any unusually long generated content still needs a larger cell.

Regression follow-up: removed every remaining UI Truncate override, which could reintroduce disappearing labels after the shared policy. Added geometry clipping checks for partially visible/outside glyphs and texture coordinates. Existing font-atlas refresh remains active.

Run `pwsh -NoProfile -File Tools/check_ui_layout.ps1` for the isolated policy checks. These do not substitute for Unity visual validation.
