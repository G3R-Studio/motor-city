# UX-6 - Полировка «Мой Motor City»: единая QA

Дата: 2026-10-12; репозиторий `G3R-Studio/motor-city`, `main`.

## Изменения по исходникам

- **Контекст вместо постоянного HUD-шума.** Страница «Мой гараж» находит ближайший по REP реально доступный, ещё закрытый обычный автомобиль, показывает именно разницу до требования, не обещает немедленную выдачу автомобиля. Supporter-exclusive и машины без визуала исключены. Страница «Автоклуб» показывает фактический остаток до недельного плана, только для вступившего игрока и ещё не полученной награды.
- **RU/EN, узкие экраны и тач.** Все три новые подписи локализованы. Существующий `CreateFrontEndModalWindow` ограничивает размеры через `Screen.safeArea`, оставляет Back в фиксированном footer, маскирует и прокручивает длинные страницы, переносит текст без резкого уменьшения шрифта, перестраивает кнопки на узких экранах. Одно короткое пояснение показывается при *первом* открытии центра за текущий runtime-сеанс и не сохраняется.
- **Свежие данные.** При каждом открытии центра и переходе по вкладкам читаются владельцы прогресса. Пока центр открыт, раз в 0,75 секунды сравниваются только примитивные снимки: КР, REP, выбранное авто, последовательность результата, серверный день и неделя. При изменении обновляется *только* активная страница, с сохранением текущей вкладки/scroll. Переход RU/EN через существующие настройки перестраивает front-end Canvas.
- **Пустые, заблокированные и завершённые состояния** остаются за владельцами: если HUD ещё не привязан, выводится `ux.sections.not_ready`; клуб без членства не изображает доступные награды, серия ночного клуба/легенды и коллекции показывают завершение по их настоящему флагу. Дополнительной кнопки входа в Yandex SDK, выдуманной награды или online-системы не создано. GitHub Pages без SDK остаётся отдельным сценарием UX-7.
- **Обращения к gameplay и overdraw.** Пока front-end Canvas скрыт в езде, он не выполняет перестройку модальных окон. Во время просмотра дорогие строки каталога и журнала не собираются в `Update()`; layout/cues пересчитываются при изменении снимка, открытии или resize, а не постоянно.
- **Ограничения.** В новом коде нет `SaveService` и вызовов начисления наград; существующие управление, гараж/навигатор/пауза, retry/continue, таймеры и балансы не переписаны. Существующий текст «как начать» в активностях не возвращался, маршрутовые кнопки туда не добавлялись.

## Автоматизированные source gates

В ручной `.github/workflows/motor-city-source-gates.yml` добавлен `python3 Tools/check_player_experience_polish.py` с 16 структурными проверками. Внешняя команда и Unity компилятор **не запускались** этим изменением; source-level инспекция ниже не заменяет ручную Unity QA. WebGL и Pages не запускать до UX-7.

## Одна итоговая проверка в Unity Editor после `git pull`

1. Открой «Мой Motor City» из главного меню и из паузы: первый раз показана **одна** короткая подсказка; при следующих открытиях её нет. Во вкладках работает «НАЗАД», нет лишних X и кнопок «маршрут» в «Активностях», Esc возвращает корректно.
2. В «Мой гараж» возьми сохранение, где следующая обычная машина ещё закрыта: подсказка показывает конкретную машину и точный остаток REP; после накопления репутации подсказка исчезает/переключается на следующую машину. Supporter-exclusive не раскрывается через подсказку. При переключении автомобиля показываются именно выбранные мастерство, история и улучшения.
3. В «Автоклубе» сравни подсказку с настоящим недельным `WeeklyContribution/WeeklyTarget`: без клуба, при прогрессе, после достижения цели и после получения награды. Ничего не начисляется повторно. Проверяй обновление после завершения активности, повторного входа и нового дня/недели.
4. Проверь RU/EN: длинные описания достижений, ночь/легенды, журнал и результаты. При 1920×1080, узком landscape и маленьком/portrait экране текст переносится и прокручивается пальцем/колесом, все кнопки и футер остаются доступны, трёхкнопочные ряды не вылезают за safe area.
5. Проверь чистое и старое сохранение, максимальные уровни и завершённые задания: вместо выдуманных наград видны реальные состояния. При недоступных системах не должно быть `NullReferenceException`. Без Yandex SDK на Github Pages никакая новая кнопка ничего не блокирует - браузерный тест позже в UX-7.
6. Проверь смену машины/КР/REP, событие результата, новый день/неделю (по реальной игровой ротации, без изменения сохранений ради теста): открытая страница обновляется без дублированных окон, а в процессе езды нет нового постоянного HUD-текста.
7. Проверь Pause → Main Menu → Continue → выбор управления, управление стрелками/рулём и тач, спринт/Retry/Continue, гараж/навигатор, `Time.timeScale`, Unity Console без новых ошибок.

**Статус:** 6/6 требований UX-6 реализованы по исходникам, **Unity Play Mode и UX-7 WebGL/release QA ожидаются**. Отметить Unity-приёмку после пользовательского «всё чётко».
